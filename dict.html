Ch 01

What is a Dictionary? The most powerful way to store related data in Python

💡 Core Concept

A dictionary is a collection of key-value pairs. Instead of accessing items by position (like a list), you access them by a meaningful key. Think of a real dictionary: you look up a word (key) and get its definition (value).

Keys must be unique and immutable (strings, numbers, tuples). Values can be anything — strings, numbers, lists, even other dicts.

Without dicts, storing a student's info is clunky:

before_dict.py — The painful way
# Without dict — parallel lists (terrible idea)
names  = ["Ahmed"]
ages   = [20]
grades = ["A"]
# To get Ahmed's grade: grades[names.index("Ahmed")] 😱

# With dict — clean, readable, powerful ✨
student = {
    "name":  "Ahmed",
    "age":   20,
    "grade": "A"
}
print(student["grade"])   # "A" — instant!
Output
A

Real-world analogies

🌍 Analogies

A real dictionary: word → definition. A phone contact: name → phone number. A restaurant menu: dish name → price. A country-code map: "EG" → "Egypt". A student record: student ID → all their data.

Everywhere you have a "label that points to a value," a dict is the right tool.

Creating Dictionaries Five different ways — know them all

creating_dicts.py
# METHOD 1: Curly braces — most common
person = {"name": "Sara", "age": 25, "city": "Alex"}

# METHOD 2: dict() constructor
car = dict(brand="Toyota", year=2022, color="white")
# Note: keys are written WITHOUT quotes here!

# METHOD 3: dict() from a list of pairs
pairs = [("x", 10), ("y", 20), ("z", 30)]
coords = dict(pairs)

# METHOD 4: fromkeys() — same value for all keys
scores = dict.fromkeys(["Ali", "Sara", "Mona"], 0)
print(scores)   # {'Ali': 0, 'Sara': 0, 'Mona': 0}

# METHOD 5: Empty dict then fill
inventory = {}
inventory["apples"]  = 50
inventory["bananas"] = 30
inventory["oranges"] = 45
print(inventory)
Output
{'Ali': 0, 'Sara': 0, 'Mona': 0}
{'apples': 50, 'bananas': 30, 'oranges': 45}
💡
What Can Be a Key?

Keys must be hashable (immutable): strings ✅, integers ✅, floats ✅, tuples ✅. Lists ❌ and dicts ❌ cannot be keys — they're mutable. Values can be anything: lists, dicts, functions, None, whatever you need.

Ch 03

Accessing Values Two ways — one safe, one not

accessing.py
student = {
    "name":  "Nour",
    "age":   22,
    "grade": "B+"
}

# WAY 1: Square brackets [] — fast, but crashes if key missing
print(student["name"])    # "Nour"
print(student["age"])     # 22
# print(student["email"]) # ← KeyError: 'email' — key doesn't exist!

# WAY 2: .get() — safe, returns None (or a default) if missing
print(student.get("grade"))          # "B+"
print(student.get("email"))          # None — no crash!
print(student.get("email", "N/A"))  # "N/A" — custom default

# Checking if key exists before access
if "name" in student:
    print(f"Name found: {student['name']}")

# Access nested value (dict inside dict)
data = {"scores": {"math": 95, "science": 88}}
print(data["scores"]["math"])   # 95
Output
Nour
22
B+
None
N/A
Name found: Nour
95
⚠️
Use .get() When You're Not Sure the Key Exists

Accessing a missing key with [] raises a KeyError and crashes your program. Use .get(key, default) when the key might not be there — it returns None or your custom default instead of crashing.

Ch 04

Adding, Modifying & Removing Dicts are mutable — change them freely

modify.py
profile = {"name": "Ali", "age": 19}

# ADD a new key-value pair
profile["email"] = "ali@example.com"
print(profile)
# {'name': 'Ali', 'age': 19, 'email': 'ali@example.com'}

# MODIFY an existing value
profile["age"] = 20   # same key, new value → overwrites
print(profile["age"])  # 20

# DELETE a key — 3 ways
del profile["email"]              # del keyword
removed = profile.pop("age")      # .pop() returns the value
print(f"Removed: {removed}")       # Removed: 20
last = profile.popitem()           # .popitem() removes last added

# UPDATE — merge another dict in
user = {"name": "Mona", "age": 21}
extra = {"city": "Giza", "age": 22}  # age will be overwritten
user.update(extra)
print(user)
# {'name': 'Mona', 'age': 22, 'city': 'Giza'}

# Python 3.9+ merge operator |
merged = user | {"country": "Egypt"}
print(merged)
Output
{'name': 'Mona', 'age': 22, 'city': 'Giza'}
{'name': 'Mona', 'age': 22, 'city': 'Giza', 'country': 'Egypt'}
⚡
setdefault() — Add Only If Missing

d.setdefault(key, value) adds the key only if it doesn't exist, then returns its value. Perfect for "initialize if not set" patterns — like building a word-count dict without checking first.

setdefault.py
counts = {}
words  = ["cat", "dog", "cat", "bird", "dog", "cat"]

for word in words:
    counts.setdefault(word, 0)  # init to 0 if not there yet
    counts[word] += 1

print(counts)
# {'cat': 3, 'dog': 2, 'bird': 1}

# Even cleaner with .get():
counts2 = {}
for word in words:
    counts2[word] = counts2.get(word, 0) + 1

print(counts2)  # {'cat': 3, 'dog': 2, 'bird': 1}
Ch 05

Dictionary Methods The complete toolkit — every method explained

.keys()
dict.keys()
Returns a view of all keys in the dict. Updates automatically if dict changes.
d.keys() → dict_keys(['a','b'])
.values()
dict.values()
Returns a view of all values. Duplicates are allowed in values (unlike keys).
d.values() → dict_values([1, 2])
.items()
dict.items()
Returns a view of (key, value) pairs as tuples. Essential for looping.
d.items() → dict_items([('a',1)])
.get()
dict.get(key, default)
Returns value for key, or default if key missing. Never raises KeyError.
d.get('x', 0) → 0 if 'x' missing
.pop()
dict.pop(key, default)
Removes and returns the value for key. Pass default to avoid KeyError on missing key.
d.pop('a') → 1, removes 'a'
.popitem()
dict.popitem()
Removes and returns the last inserted (key, value) pair. Useful for LIFO processing.
d.popitem() → ('last_key', val)
.update()
dict.update(other)
Merges another dict into this one. Existing keys are overwritten.
d.update({'c': 3}) adds/overwrites
.setdefault()
dict.setdefault(key, val)
If key exists: return its value. If missing: insert key with val, return val.
d.setdefault('x', 0)
.copy()
dict.copy()
Returns a shallow copy. Changes to copy don't affect original (for top-level keys).
new = d.copy()
.clear()
dict.clear()
Removes all items. Dict becomes empty {} but the variable still exists.
d.clear() → {}
len()
len(dict)
Returns the number of key-value pairs. One of Python's built-in functions, works on dicts.
len({'a':1, 'b':2}) → 2
in / not in
key in dict
Checks if a KEY exists in the dict. Does NOT check values. O(1) speed.
'name' in d → True or False
methods_demo.py — All key methods in action
d = {"a": 1, "b": 2, "c": 3}

print(list(d.keys()))    # ['a', 'b', 'c']
print(list(d.values()))  # [1, 2, 3]
print(list(d.items()))   # [('a', 1), ('b', 2), ('c', 3)]

# Safe get with default
print(d.get("z", 99))    # 99  — "z" doesn't exist

# Pop removes and returns
val = d.pop("b")
print(val, d)            # 2  {'a': 1, 'c': 3}

# in checks KEYS only
print("a" in d)          # True
print(1 in d)            # False — 1 is a VALUE, not a key
print(1 in d.values())   # True — check values explicitly

# Length
print(len(d))             # 2 (after pop)
Output
['a', 'b', 'c']
[1, 2, 3]
[('a', 1), ('b', 2), ('c', 3)]
99
2 {'a': 1, 'c': 3}
True
False

Ch 06

Looping Through Dicts Four essential patterns — use .items() the most

looping.py — All four patterns
menu = {
    "Burger":  45,
    "Pizza":   80,
    "Pasta":   60,
    "Salad":   30
}

# PATTERN 1: Loop over keys (default behavior)
for item in menu:
    print(item)           # Burger, Pizza, Pasta, Salad

# PATTERN 2: Loop over values
for price in menu.values():
    print(price)          # 45, 80, 60, 30

# PATTERN 3: Loop over BOTH — most useful ⭐
for item, price in menu.items():
    print(f"{item:10} → {price} EGP")

# PATTERN 4: Loop with condition
print("\nAffordable items (under 50 EGP):")
for item, price in menu.items():
    if price < 50:
        print(f"  ✅ {item} — {price} EGP")

# Sorted loop
for item in sorted(menu):         # alphabetical by key
    print(item)

for k, v in sorted(menu.items(), key=lambda x: x[1]):
    print(f"{k}: {v}")               # sorted by price
Output (items loop)
Burger → 45 EGP
Pizza → 80 EGP
Pasta → 60 EGP
Salad → 30 EGP
Affordable items (under 50 EGP):
✅ Burger — 45 EGP
✅ Salad — 30 EGP
⚡
Always Use .items() When You Need Both Key and Value

The most common dict loop pattern in real Python code is for k, v in d.items():. This unpacks each (key, value) tuple automatically. Don't do for k in d: v = d[k] — that's two lookups instead of one.

Ch 07

Dict Comprehension Build entire dictionaries in one elegant line

⚡ Concept

Dict comprehension is the one-liner syntax for building a dictionary. Formula: {key_expr: val_expr for item in iterable if condition}. It's faster, more readable, and very Pythonic.

dict_comprehension.py
# Basic: squares dict {num: num²}
squares = {x: x**2 for x in range(1, 6)}
print(squares)
# {1: 1, 2: 4, 3: 9, 4: 16, 5: 25}

# With condition: only even numbers
even_sq = {x: x**2 for x in range(1, 11) if x % 2 == 0}
print(even_sq)
# {2: 4, 4: 16, 6: 36, 8: 64, 10: 100}

# Swap keys and values
original = {"a": 1, "b": 2, "c": 3}
swapped  = {v: k for k, v in original.items()}
print(swapped)    # {1: 'a', 2: 'b', 3: 'c'}

# Build from two lists with zip()
students = ["Ali", "Sara", "Mona"]
grades   = [95, 88, 72]
report = {name: grade for name, grade in zip(students, grades)}
print(report)     # {'Ali': 95, 'Sara': 88, 'Mona': 72}

# Transform existing dict: convert Celsius to Fahrenheit
celsius = {"Cairo": 35, "Alex": 28, "Aswan": 41}
fahrenheit = {city: (temp * 9/5) + 32 for city, temp in celsius.items()}
print(fahrenheit)
# {'Cairo': 95.0, 'Alex': 82.4, 'Aswan': 105.8}

# Filter: only passing students (grade >= 60)
all_grades = {"Ali": 95, "Sara": 45, "Mona": 72, "Omar": 30}
passing = {k: v for k, v in all_grades.items() if v >= 60}
print(passing)    # {'Ali': 95, 'Mona': 72}
Ch 08

Nested Dictionaries Dicts inside dicts — modeling real-world complex data

🪆 Concept

A dict's value can itself be a dict. This creates nested dictionaries — the most natural way to represent hierarchical data like student records, JSON APIs, configuration files, or a school database.

nested_dicts.py — School database
school = {
    "Ahmed": {
        "age":    20,
        "grades": {"math": 95, "science": 88, "english": 79},
        "passed": True
    },
    "Sara": {
        "age":    21,
        "grades": {"math": 72, "science": 91, "english": 85},
        "passed": True
    },
    "Omar": {
        "age":    19,
        "grades": {"math": 45, "science": 52, "english": 40},
        "passed": False
    }
}

# Access nested value — chain the keys
print(school["Ahmed"]["grades"]["math"])  # 95

# Modify nested value
school["Omar"]["grades"]["math"] = 65    # Omar retook the exam

# Loop through nested dict
for name, info in school.items():
    avg = sum(info["grades"].values()) / len(info["grades"])
    status = "✅" if info["passed"] else "❌"
    print(f"{status} {name:8} | Avg: {avg:.1f}")

# Safe access on deeply nested key
ahmed_eng = school.get("Ahmed", {}).get("grades", {}).get("english", 0)
print(f"Ahmed's English: {ahmed_eng}")   # 79
Output
95
✅ Ahmed | Avg: 87.3
✅ Sara | Avg: 82.7
❌ Omar | Avg: 52.3
Ahmed's English: 79
💡
Chaining .get() for Safe Deep Access

d.get("a", {}).get("b", {}).get("c", default) safely accesses nested keys without crashing. Each .get() returns an empty dict if the key is missing, allowing the next .get() to safely continue.

real_world_nested.py — Config and JSON-like data
# Real-world: API response / config file structure
app_config = {
    "database": {
        "host":     "localhost",
        "port":     5432,
        "name":     "myapp_db"
    },
    "server": {
        "host":     "0.0.0.0",
        "port":     8000,
        "debug":    False
    },
    "features": ["auth", "payments", "notifications"]
}

# Access values
db_port = app_config["database"]["port"]
print(f"DB running on port: {db_port}")   # 5432

# Update nested value
app_config["server"]["debug"] = True

# Add a new nested key
app_config["cache"] = {"backend": "redis", "timeout": 300}
