Ch 01

What is a Set? A collection that never repeats itself — like a guest list

💡 Core Concept

A set is a collection of unique, unordered items. Think of it like a real-world set in mathematics — a bag where every item appears only once, and the order doesn't matter.

If you add the same item twice, Python silently ignores the second one. No duplicates. Ever.

Imagine you're counting which cities students come from. Some cities repeat — but you only want to know which unique cities exist:

intro_set.py
# Without sets — messy manual work
cities = ["Cairo", "Alex", "Cairo", "Giza", "Alex", "Cairo"]
unique = []
for city in cities:
    if city not in unique:
        unique.append(city)
print(unique)   # ['Cairo', 'Alex', 'Giza']

# WITH a set — one line, instant ✨
unique_cities = set(cities)
print(unique_cities)   # {'Cairo', 'Alex', 'Giza'} — order may vary!
Output
{'Cairo', 'Alex', 'Giza'}
(order is not guaranteed in sets)
💡
The Three Rules of Sets

1. No duplicates — each element appears exactly once. 2. Unordered — you can't access elements by index. 3. Elements must be hashable — strings, numbers, tuples work. Lists don't (they're mutable).

Real-World Analogies

🌍 Think Of It This Way

A pizza topping list — you either have pepperoni or you don't. Ordering it twice doesn't give you double pepperoni (on a set, anyway). A social media follower list — one person can only follow you once. Raffle ticket stubs — each unique number appears once.

Ch 02

Creating Sets Four different ways — know them all

creating_sets.py
# METHOD 1: Curly braces {} with values
fruits = {"apple", "banana", "cherry"}
print(fruits)       # {'apple', 'banana', 'cherry'}

# METHOD 2: set() with a list
numbers = set([1, 2, 3, 2, 1])
print(numbers)      # {1, 2, 3} — duplicates removed!

# METHOD 3: set() with a string — each CHAR becomes an element
letters = set("hello")
print(letters)      # {'h', 'e', 'l', 'o'} — 'l' appeared twice, kept once

# METHOD 4: Empty set — MUST use set(), not {}
empty = set()
print(empty)        # set()
print(type(empty))  # <class 'set'>

# Mixed types in a set
mixed = {1, "hello", 3.14, True}
print(mixed)
☠️
The Empty Set Trap — Beginner #1 Mistake

empty = {} does NOT create an empty set. It creates an empty dictionary! Always use set() for an empty set. This is one of Python's most common gotchas.

empty_trap.py
wrong = {}            # This is a DICT not a set!
right = set()         # This is an empty set ✓

print(type(wrong))    # <class 'dict'> ← WRONG!
print(type(right))    # <class 'set'>  ← CORRECT
Output
<class 'dict'>
<class 'set'>

⚡
Why O(1) Lookup Matters

With a list, Python checks every item one by one to see if something exists — O(n). With a set, it uses a hash table and jumps directly to where the item would be — O(1). For 1 million items, the difference is seconds vs microseconds.

s = {1, 2, 3}

# add — safe duplicate attempt
s.add(4)
s.add(2)        # already there — ignored silently
print(s)          # {1, 2, 3, 4}

# remove vs discard
s.discard(99)    # no error, 99 doesn't exist
# s.remove(99)   # would raise KeyError!

A = {1, 2}
B = {1, 2, 3, 4}
print(A.issubset(B))    # True  — A ⊆ B
print(B.issuperset(A))  # True  — B ⊇ A
print(A.isdisjoint({5,6}))  # True — no common elements

Ch 05

Set Operations The superpower — math built into Python syntax

⚙️ The Big Four

These four operations come from mathematics and are built directly into Python. You can use either operators (|, &, -, ^) or method names — both produce the same result.

1. Union — Everything from Both

A | B — Union All elements from A plus all elements from B. If something is in either set, it's in the union. Duplicates still removed.
A = {1,2,3}   B = {3,4,5}
A | B = {1,2,3,4,5}
union.py
A = {1, 2, 3}
B = {3, 4, 5}

print(A | B)              # {1, 2, 3, 4, 5} — operator
print(A.union(B))         # {1, 2, 3, 4, 5} — method (same result)

# Real world: combine two friend lists
friends_A = {"Sara", "Ahmed", "Nour"}
friends_B = {"Ahmed", "Mona", "Khaled"}
all_friends = friends_A | friends_B
print(all_friends)
# {'Sara', 'Ahmed', 'Nour', 'Mona', 'Khaled'} — Ahmed appears once

2. Intersection — What They Share

A & B — Intersection Only elements that exist in both sets simultaneously. The overlap. If it's in only one, it's excluded.
A = {1,2,3}   B = {3,4,5}
A & B = {3}
intersection.py
A = {1, 2, 3}
B = {3, 4, 5}

print(A & B)                 # {3}
print(A.intersection(B))    # {3}

# Real world: find mutual friends
ahmed_friends = {"Sara", "Mona", "Ali"}
sara_friends  = {"Mona", "Khaled", "Ali"}
mutual = ahmed_friends & sara_friends
print(f"Mutual friends: {mutual}")  # {'Mona', 'Ali'}

3. Difference — In A but Not B

A - B — Difference Elements in A that are NOT in B. What's unique to A. Note: order matters — A-B ≠ B-A.
A = {1,2,3}   B = {3,4,5}
A - B = {1,2}   B - A = {4,5}
difference.py
A = {1, 2, 3}
B = {3, 4, 5}

print(A - B)              # {1, 2}  — in A, not in B
print(B - A)              # {4, 5}  — in B, not in A
print(A.difference(B))    # {1, 2}  — same as A - B

# Real world: find students who failed (in registered but not in passed)
registered = {"Ali", "Sara", "Mona", "Ahmed"}
passed     = {"Sara", "Ahmed"}
failed     = registered - passed
print(f"Students who failed: {failed}")  # {'Ali', 'Mona'}

4. Symmetric Difference — Everything Unique

A ^ B — Symmetric Difference Elements in either A or B, but NOT in both. Excludes the overlap. Think "XOR" (exclusive or).
A = {1,2,3}   B = {3,4,5}
A ^ B = {1,2,4,5}
symmetric_diff.py
A = {1, 2, 3}
B = {3, 4, 5}

print(A ^ B)                         # {1, 2, 4, 5}
print(A.symmetric_difference(B))     # {1, 2, 4, 5}

# Equivalent to: (A | B) - (A & B)
print((A | B) - (A & B))            # {1, 2, 4, 5} — same result

# Real world: things changed between two versions
v1_features = {"login", "upload", "profile"}
v2_features = {"login", "upload", "dashboard", "search"}
changes = v1_features ^ v2_features
print(f"What changed: {changes}")
# {'profile', 'dashboard', 'search'}

In-Place Operations (modify the set directly)

inplace_ops.py
A = {1, 2, 3}
B = {3, 4, 5}

# |=  (update in place — union)
A |= B
print(A)     # {1, 2, 3, 4, 5}

# &=  (intersection in place)
A = {1, 2, 3}
A &= B
print(A)     # {3}

# -=  (difference in place)
A = {1, 2, 3}
A -= B
print(A)     # {1, 2}

# ^=  (symmetric difference in place)
A = {1, 2, 3}
A ^= B
print(A)     # {1, 2, 4, 5}
Ch 06

Frozen Sets An immutable set — locked forever after creation

🧊 Concept

A frozenset is a set that can never be changed after creation. No adding, no removing. It's the "read-only" version of a set.

Because it's immutable, it's hashable — meaning you can use a frozenset as a key in a dictionary or as an element inside another set. Regular sets can't do this.

frozenset_demo.py
# Create a frozenset
fs = frozenset([1, 2, 3, 2, 1])
print(fs)          # frozenset({1, 2, 3})

# Read operations work fine
print(2 in fs)     # True
print(len(fs))     # 3

# Write operations FAIL
# fs.add(4)        # AttributeError: 'frozenset' has no .add()
# fs.remove(1)     # AttributeError: 'frozenset' has no .remove()

# All set operations still work (return new frozensets)
fs2 = frozenset([3, 4, 5])
print(fs | fs2)   # frozenset({1, 2, 3, 4, 5})
print(fs & fs2)   # frozenset({3})

# Use frozenset as dict KEY (impossible with regular set)
d = {}
d[frozenset([1,2])] = "group A"
d[frozenset([3,4])] = "group B"
print(d)
# {frozenset({1, 2}): 'group A', frozenset({3, 4}): 'group B'}

Ch 07

Set Comprehension Build sets in one elegant line — like a pro

⚡ Concept

Set comprehension is the one-liner syntax for building a set. Same idea as list comprehension, but uses {} and automatically removes duplicates. Formula: {expression for item in iterable if condition}

set_comprehension.py
# Basic: squares of 1–10
squares = {x**2 for x in range(1, 11)}
print(squares)
# {1, 4, 9, 16, 25, 36, 49, 64, 81, 100}

# With condition: only even squares
even_sq = {x**2 for x in range(1, 11) if x % 2 == 0}
print(even_sq)
# {4, 16, 36, 64, 100}

# Dedup naturally: first letters of words (some letters repeat)
words = ["apple", "ant", "banana", "ball", "cherry"]
first_letters = {w[0] for w in words}
print(first_letters)   # {'a', 'b', 'c'}

# Uppercase unique characters from a string
chars = {c.upper() for c in "mississippi" if c != "i"}
print(chars)            # {'M', 'S', 'P'}

# Find all unique remainders when dividing 1-20 by 3
remainders = {n % 3 for n in range(1, 21)}
print(remainders)       # {0, 1, 2}
⚡
List Comprehension vs Set Comprehension

Use [x for x in ...] for a list (ordered, duplicates allowed). Use {x for x in ...} for a set (unordered, no duplicates, faster membership testing). The only visible difference: square brackets vs curly braces.

when_to_use.py — Real-world decisions
# USE A LIST when order and duplicates matter
exam_scores = [95, 72, 88, 72, 91]  # 72 appears twice — that's valid!

# USE A SET when you need uniqueness or fast lookup
visited_pages = {"/home", "/about", "/contact"}
if "/home" in visited_pages:     # O(1) — instant even with millions!
    print("Already visited")

# USE A DICT when you need to map one thing to another
student_grades = {"Ali": 95, "Sara": 88, "Mona": 72}

# SPEED COMPARISON — set vs list membership test
import time
big_list = list(range(1_000_000))
big_set  = set(range(1_000_000))

t1 = time.time()
999_999 in big_list
print(f"List: {time.time()-t1:.4f}s")   # ~0.01s — scans all items

t2 = time.time()
999_999 in big_set
print(f"Set:  {time.time()-t2:.6f}s")   # ~0.000001s — instant hash!
